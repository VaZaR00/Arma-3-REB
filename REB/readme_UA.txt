Система РЕБ (Радіоелектронна боротьба)
========================================

Суть проєкту
-------------
РЕБ — це модульна система для Arma 3, яка реалізує об'єкти радіоелектронної боротьби (РЕБ) з підтримкою взаємодії через ACE3, гнучким налаштуванням параметрів та мультиплеєрною сумісністю.

Система дозволяє додавати на карту об'єкти РЕБ (наприклад, глушники, станції подавлення), керувати їхнім станом, радіусом дії, потужністю, а також взаємодіяти з ними через меню ACE. Вся логіка побудована на об'єктно-орієнтованому підході (OOP у SQF), що забезпечує розширюваність і зручність підтримки.

Основні функції
----------------
- **Ініціалізація та реєстрація** (`fn_reb.sqf`, `fn_rebInit.sqf`):
  Створення та налаштування екземплярів РЕБ, реєстрація у глобальній базі, синхронізація між сервером і клієнтами.
- **Інтеграція з ACE** (`ace_actions/fn_createAceActionsForObjectReb.sqf`, `fn_removeAceActionsForObjectReb.sqf`):
  Додавання та видалення користувацьких ACE-дій для керування об'єктами РЕБ (увімкнення/вимкнення, налаштування параметрів).
- **Мережеві виклики** (`fn_remoteCall.sqf`):
  Безпечне виконання функцій на сервері або клієнтах з поверненням результату.
- **Керування параметрами** (`fn_setRange.sqf`, `fn_setStrenght.sqf`, `fn_setValueDialog.sqf`):
  Зміна радіусу, потужності та інших параметрів об'єктів РЕБ через діалоги та меню ACE.
- **Керування розміщенням** (`placement/`):
  Скрипти для розміщення, прикріплення, від'єднання об'єктів РЕБ та перевірки можливості маніпуляцій.

Основні класи
--------------
- **OO_OBJECT_REB** (`Classes/OBJECT_REB.sqf`):
  Головний клас об'єкта РЕБ. Містить методи керування станом, параметрами та взаємодією з гравцями.
- **OO_OBJECT_REB_DB** (`Classes/OBJECT_REB_DB.sqf`):
  База даних усіх об'єктів РЕБ на місії. Дозволяє шукати, реєструвати та видаляти об'єкти.
- **OO_REB_DB** (`Classes/REB_DB.sqf`):
  Глобальна база класів РЕБ, відповідає за створення та зберігання унікальних класів для різних типів об'єктів.
- **OO_REB** (`Classes/REB.sqf`):
  Базовий клас для логіки РЕБ, може бути розширений для різних типів пристроїв.

Особливості
-----------
- Повна підтримка мультиплеєра (усі дії синхронізуються через сервер).
- Гнучка система макросів та інкапсуляції (`includes/defines.h`, `generic.h`, `oop.h`).
- Легко розширюється для нових типів пристроїв РЕБ та взаємодій.
- Інтеграція з ACE3 для зручного інтерфейсу користувача.

РЕБ — це потужний і розширюваний фреймворк для створення та керування об'єктами радіоелектронної боротьби у місіях Arma 3.

Використання
------------
Щоб створити та ініціалізувати об'єкт РЕБ, використовуйте такий виклик функції:

    [object, radius, deadzone, strength, isAttachable, canModifyRange, canModifyStrength, isActive] call REB_fnc_reb;

**Параметри:**
- `object` (Object): Ігровий об'єкт, до якого буде прикріплено систему РЕБ.
- `radius` (Number): Ефективний радіус дії РЕБ.
- `deadzone` (Number): Радіус "мертвої зони", де ефект не діє.
- `strength` (Number): Потужність (сила) ефекту РЕБ.
- `isAttachable` (Bool): Чи можна прикріплювати/від'єднувати РЕБ гравцями.
- `canModifyRange` (Bool): Чи можна змінювати радіус через меню ACE.
- `canModifyStrength` (Bool): Чи можна змінювати потужність через меню ACE.
- `isActive` (Bool): Чи буде РЕБ активним при створенні.

**Приклад:**

    [myObject, 100, 30, 0.5, true, true, true, true] call REB_fnc_reb;

Це створить екземпляр РЕБ на `myObject` з радіусом 100м, "мертвою зоною" 30м, потужністю 0.5, можливістю прикріплення, змінними радіусом і потужністю, та активним за замовчуванням.
